# Product Security Study Roadmap

> **Goal:** Become a Product Security Engineer through structured learning, hands-on practice, and real-world projects.

---

# Learning Philosophy

For every topic, follow the same workflow:

```text
Learn
    ↓
Understand
    ↓
Practice
    ↓
Document
    ↓
Commit
    ↓
Move to Next Topic
```

The objective is to **build real skills first**. The GitHub repository is evidence of that learning.

# Daily Study Routine

```text

30 min     Document in GitHub
15 min     Revision
```

---

# Weekly Goals

* Complete one major topic.
* Perform hands-on practice.
* Commit your notes to GitHub.
* Revise previous topics.
* Solve interview questions.

---

# Success Criteria

By the end of this roadmap, you should be able to:

* Explain Product Security concepts confidently.
* Troubleshoot Linux systems.
* Understand networking and web protocols.
* Secure containers and Kubernetes.
* Review cloud security configurations.
* Participate in secure design reviews.
* Build and secure CI/CD pipelines.
* Perform practical security investigations.
* Confidently interview for Product Security roles.

---

# Guiding Principles

* Learn deeply rather than quickly.
* Practice every concept.
* Keep GitHub updated as proof of learning.
* Focus on understanding instead of memorization.
* Stay consistent—small progress every day leads to long-term success.
