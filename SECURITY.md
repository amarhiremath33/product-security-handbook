# Security Policy

This repository contains learning material, lab instructions and small helper scripts.

## Reporting a Problem

Please report privately — **do not open a public issue** — if you find:

- A lab step or script that could damage a system beyond what is described
- Advice that is insecure or dangerously outdated
- Accidentally committed secrets or personal data

Use GitHub's **private vulnerability reporting**: the **Security** tab → **Report a vulnerability**.

Please include the file, the problem, and a suggested fix if you have one. You can expect an acknowledgement within 7 days.

## Scope

- Scripts in `labs/` are intended for **lab machines only**. They are provided as-is under the MIT License.
- Third-party tools and links are outside this repository's control; report issues to their maintainers.

## Safe Use of the Labs

- Run labs only on machines you own or are authorised to test.
- Use disposable VMs or containers and take snapshots before system-changing (⚠️) steps.
- Never use lab credentials anywhere else.
